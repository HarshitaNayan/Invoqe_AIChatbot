# Hynex – AI Learning Assistant

Hynex is a chat-based AI assistant with a modern, ChatGPT-style web interface. It is built with **FastAPI** and the **Gemini API**, and it falls back to a local NLP matcher when the AI is not available.

> **Status:** Early version (v0.1). The core chatbot works, and many features are still pending. See [Planned features](#planned-features).

Built as part of the Invoqe AI/ML Developer internship (Task: AI Chatbot & NLP System).


## Features

**Chat experience**
- Custom Hynex-branded interface with a dark theme
- Streaming replies that appear word by word
- Markdown rendering with code blocks and a **Copy** button
- Suggestion chips on the welcome screen
- Responsive layout that works on mobile

**Chat management**
- Multiple chats listed in a sidebar
- **Pin** chats, which appear under a separate "Pinned" section
- **Delete** chats, with a confirmation prompt
- Chats are saved in the browser, so they stay after a refresh

**AI and NLP**
- Answers generated by the **Gemini API**
- Remembers the last 10 messages of the conversation
- **Retrieval (RAG-style):** the closest entries from the knowledge base (`data/intents.json`) are found with TF-IDF and cosine similarity, then passed to the model as context
- **Offline fallback:** if there is no API key or the API call fails, the bot answers from the local TF-IDF intent matcher instead of crashing

## How it works

1. The user sends a message from the web interface.
2. The FastAPI `/chat` endpoint cleans the text (lowercase, punctuation and stopword removal) and finds the closest knowledge-base entries using TF-IDF and cosine similarity.
3. The message, recent chat history and the retrieved context are sent to the Gemini API.
4. The reply is streamed back and shown in the interface.
5. If the API is unavailable, the local matcher replies instead.

## Setup

1. Clone the repository
```bash
   git clone https://github.com/HarshitaNayan/Invoqe_AIChatbot.git
   cd Invoqe_AIChatbot
```
2. Install the dependencies
```bash
   pip install -r requirements.txt
```
3. Get a free API key from [Google AI Studio](https://aistudio.google.com/).
4. Create a file named `.env` in the project folder and add your key:
```
   GEMINI_API_KEY=your_api_key_here
```
   Optional: choose a model with `GEMINI_MODEL=gemini-flash-latest`.

> Never upload your `.env` file. It is already listed in `.gitignore`.

## Run

```bash
python -m uvicorn app.main:app --reload
```

Then open **http://127.0.0.1:8000** in your browser.

If no API key is set, the app still runs in **offline mode** and answers from the local knowledge base.

## Known limitations

- Free Gemini keys have daily request limits. When the limit is reached, the app switches to offline mode.
- The knowledge base contains sample entries, so offline answers are limited.
- Chats are stored only in the browser, not on a server.
